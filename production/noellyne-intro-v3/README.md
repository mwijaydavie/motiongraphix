# Noellyne introduction v3 — work in progress

Full-length 33.9-second vertical preview using the original voice, four additional pose stills and the v1 independently pivoting head and raised-arm layers in two wave shots. The first wave decays into a hold rather than oscillating continuously. Other shots use still poses and a gentle camera push-in; cuts are not continuous rigged transitions.

Mouth opening follows audio volume, not phonemes, and is not reliable Kiswahili lip sync. Blink is present only in the wave shot and substitutes a closed-eye image. No independent wrist, fingers, gaze or articulating elbows. The rig uses masks and AI-inpainted plates; seams and geometry inconsistencies can occur. Character and pose proportions vary across the generated images. Voice was selected as generic Swahili because sw-TZ was unavailable. Outfit intentionally unchanged. This preview is not a finished character performance.

Run `python production/noellyne-intro-v3/render.py` after installing `production/noellyne-intro/requirements.txt`. Requires voice and character assets already in this repo. Sampled frames from each shot for basic visual QC; no frame-by-frame seam or phonetic validation performed.
