# Noellyne: The shopping list

A ~29-second Kiswahili/Swanglish narrated motion-comic about impulse shopping: one item becomes five, the actual errand is forgotten, and a quick question helps check an impulse purchase. Original voice was synthesized with the previously selected generic Swahili voice, not VoiceStudio and not necessarily a Tanzanian accent. Editorial cards paraphrase the speech and are timed approximately; they are not word-accurate captions.

This is a deliberately honest motion-comic made with still poses, shot cuts, camera moves and animated title cards. It is **not** a talking character or a jointed rig, and it does not fix phonetic lip-sync. Character artwork varies slightly between poses. Quality check: sampled one frame from each of six shots; audio-to-card synchronization not independently reviewed by ear. Run `python production/noellyne-new-story/render.py` after installing `production/noellyne-intro/requirements.txt`.

## VoiceStudio investigation
[VoiceStudio](https://github.com/debpalash/VoiceStudio) is an open-source local voice studio with TTS, voice design/cloning, transcription, video dubbing, and local API. It might help produce consistent, reusable narration or dubbed versions, but it does not by itself animate Noellyne's face or solve phoneme alignment. The app's [license section](https://github.com/debpalash/VoiceStudio#license--responsible-use) specifies AGPL-3.0 for the app and separate model/voice licenses; check each before distribution and use cloned voices only with permission. Its [CPU GGUF docs](https://github.com/debpalash/VoiceStudio/blob/main/docs/engines/omnivoice-gguf.md) say the Q4 model is around 659 MB, plus auxiliary files. This environment has no NVIDIA GPU and only ~3.8 GiB RAM. A connection to the required Hugging Face model host failed in this sandbox, so no VoiceStudio engine was installed or audio generated/tested with it. Swahili/Tanzanian accent and commercial-use model terms remain to be verified, not assumed.
